# Yass Noir · Private Archive Blueprint

## Visual sequence

1. **Editorial**: la imagen más legible y luminosa abre la secuencia.
2. **Gate**: un panel oscuro interrumpe la lectura y marca el cambio de acceso sin explicar demasiado.
3. **Fragment**: una imagen real queda deliberadamente recortada, oscura y desenfocada para insinuar presencia sin convertirse en una fotografía rota o vacía.

## Desktop

- Tres columnas asimétricas: editorial dominante, gate intermedio, fragmento más estrecho.
- Las tres tarjetas comparten altura para mantener composición editorial.
- El fragmento utiliza crop, blur, sombra y overlay para conservar aproximadamente una relación visual de 30% visible / 70% oculto.
- En dispositivos con hover, el fragmento responde con un cambio mínimo de enfoque y escala, sin revelarse por completo.

## Mobile

Orden vertical intencional:

1. Statement del archivo.
2. Editorial principal.
3. Gate privado.
4. Fragmento oscuro.

La fotografía principal es la pieza más alta; el gate y el fragmento son progresivamente más cortos para que el usuario sienta avance, no una repetición de tres tarjetas iguales.

## Principle

La interfaz no explica el acceso. Lo convierte en una progresión visual: **ves → te detienes → intuyes**.
